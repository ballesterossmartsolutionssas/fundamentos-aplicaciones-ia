# Posters para probar en Colab

Estos archivos sirven para la seccion 9 del notebook, donde se sube una caratula externa y se muestran los 5 generos con mayor probabilidad.

Archivos:

- `avengers_endgame_2019.jpg`
  - Generos esperados aproximados: Action, Adventure, Drama, Sci-Fi
  - Recomendado para probar primero.

- `fast_and_furious_example.jpg`
  - Generos esperados aproximados: Action, Crime, Thriller

- `saaho_2019.jpg`
  - Generos esperados aproximados: Action, Thriller

Uso:

1. Cuando Colab llegue a la seccion 9, ejecuta la celda.
2. Dale clic a `Choose files`.
3. Abre esta carpeta y sube uno de estos `.jpg`.
4. Compara los generos esperados con el top 5 que imprima el modelo.
